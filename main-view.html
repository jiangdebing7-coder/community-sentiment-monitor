More settings

Unresolved deliveries are kept for verification. Disabling a monitor stops collection and sending; manage its scheduled task in Cindy Automation.

Daily task in Cindy

Set up daily task opens Cindy’s automation creation page. Check the daily time and time zone there, choose your model and save. This plugin cannot silently create a schedule or verify a saved draft.

Use Cindy chat instead

Copy this instruction into a normal Cindy conversation to create the exact daily schedule with your selected model.

If you change the time later, update the existing task in Cindy Automation. Avoid creating duplicates. Your computer and Cindy must be online when it runs.
